# Play 스토어 등록

등록 문구는 `listing-ko.md`(기본 언어), `listing-en.md`에 있다. 아래는 문구 말고 Play Console에서 채워야 하는 것들이다.

앱 화면은 한국어만 있다. 영어 리스팅은 스토어 소개 문구다.

공개 트랙(프로덕션·공개 테스트·닫힌 테스트)은 쓰지 않는다. 배포는 `internal-*` 태그로 Play 내부 테스트까지다. 방송 녹음의 저작권 검토 전에는 이 범위를 넘기지 않는다.

## 이미지

| 항목 | 규격 | 상태 |
|---|---|---|
| 앱 아이콘 | 512×512 PNG | `icon-512.png` — 2026-11-03 앱 카세트 그림으로 교체 |
| 그래픽 이미지 | 1024×500 PNG | `feature-graphic.png`(한국어), `feature-graphic-en.png`(영어) — 2026-11-03 같은 카세트로 다시 만듦 |
| 휴대전화 스크린샷 | 2~8장, 세로 9:16 권장, 각 변 320~3840px | **없음**. 기기나 시뮬레이터에서 찍어야 한다 |
| 태블릿 스크린샷 | 선택 | 없으면 '태블릿에 최적화되지 않음'으로 표시된다 |

스크린샷으로 쓸 만한 장면: 채널 목록, 재생 중인 플레이어, 녹음 중, 새 테이프(길이·색깔), 보관함, 테이프 재생.

## 스토어 설정 (제안 — Console에서 확정)

- 앱 또는 게임: **앱** / 카테고리: **음악·오디오**
- 태그: 라디오, 카세트, 레트로
- 광고 포함: **아니요**
- 인앱 구매: **없음**
- 기본 언어: 한국어. 영어 리스팅은 소개 문구용이며 앱 화면은 바뀌지 않는다
- 콘텐츠 등급: 앱 화면에 폭력·선정성·도박은 없다. 사용자가 아무 스트림이나 재생할 수 있으므로, IARC에서 사용자 제공 오디오를 어떻게 답할지는 설문 전에 확인한다
- 대상 연령층: 어린이 대상이 아니다

## 데이터 보안 양식

개발자에게 수집되거나 공유되는 데이터는 없다. 개인정보처리방침(`store/legal/privacy-policy-ko.md`)과 같은 내용으로 신고한다.

- 이름·이메일·전화번호·위치(정확)·연락처·사진·금융 정보·앱 활동·기기 ID·충돌 로그: **수집 안 함**
- 전송은 재생하는 스트림 주소, 적어 둔 로고 주소, 처음 받는 Google Fonts 글꼴뿐이다. 개발자 서버로 모이지 않는다
- 앱을 삭제하면 기기 안 채널·테이프·오디오가 지워진다

## 개인정보처리방침

`store/legal/privacy-policy-ko.md`(기본), `privacy-policy-en.md`. Pages 주소:

- KO: https://nicejhkim.github.io/mixtape_docs/ko/privacy/
- EN: https://nicejhkim.github.io/mixtape_docs/en/privacy/

앱이 바뀌어 수집 항목이 달라지면 `_includes/legal/`의 시행일과 함께 고친다.

## 배포 태그

| 태그 | 가는 곳 |
|---|---|
| `internal-*` | Android Play 내부 테스트 |
| `testflight-*` | iOS TestFlight 내부 테스트 |

가운데 토막이 버전 이름이 된다(`internal-1.0.1-3` → `1.0.1`). 꼴이 맞지 않으면 `pubspec.yaml`의 version을 쓴다. 공개 트랙 워크플로는 없다.

## 막힌 것

- **스크린샷**: 공개 출시를 하게 되면 2장 이상 필수. 실기기에서 찍어야 한다.
- **공개 출시**: 저작권 검토 전. 내부 테스트만 한다.
- 개인정보처리방침 URL — Pages 기준은 위 주소.
